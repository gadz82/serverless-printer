# ManifestTemplateCatalog

## Behavior

Reads and validates the manifest eagerly, then resolves a template by exact id or slug, including the reserved _smoke slug.

## Why

The deployed bundle is the source of truth; there is no database or runtime template registry.

## Invariants

- Malformed manifests fail cold start.
- Duplicate ids/slugs and invalid slugs are rejected.

## Failure modes

Unknown ids return null and become TEMPLATE_NOT_FOUND; manifest defects fail before jobs are processed.

## History

R-003, R-012, S-005, S-006, S-014, ADR-005, ADR-006.
