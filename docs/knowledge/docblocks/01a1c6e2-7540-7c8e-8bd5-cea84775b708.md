# Load test

## Behavior

Sends LOAD_TEST_JOBS generic-report jobs cycling through 1-page/20-page and plain/PDF-A, polls the callback queue for unique refIds, and reports mixed and 20-page throughput, p95 latency, Max Memory Used and errors. It can emit a Power Tuning SQS event and optionally enforce the candidate target.

## Why

The product needs measured capacity without adding a monitoring dependency; the harness uses the deployed queue, SQS callbacks and optional CloudWatch Logs.

## Invariants

- Jobs are capped at 200 and batches respect the 10-message/256 KB SQS limits.
- Failed sends are reported while accepted jobs are still polled.
- 20-page target enforcement uses 20-page throughput and p95, not the mixed aggregate.
- Power Tuning events use the last receive count so failures surface.

## Failure modes

Send failures, invalid/unsuccessful results, missing results and target misses exit non-zero with the affected refIds.
