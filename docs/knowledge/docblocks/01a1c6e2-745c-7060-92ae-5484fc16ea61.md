# S3PdfDestination

## Behavior

PUTs the rendered PDF bytes to an HTTPS presigned URL with Content-Type application/pdf, a bounded timeout and an explicit Content-Length. Loopback, link-local, metadata and non-routable targets are always rejected; private VPC endpoints require an explicit opt-in.

## Why

The s3 channel must deliver the PDF itself, while a caller-controlled presigned URL is still an outbound request that needs SSRF and pinning protections.

## Invariants

- HTTPS only and no redirects.
- The validated address is pinned for the PUT.
- The result for s3 omits printing and printingExpiresAt.
- Loopback and metadata targets are never allowed.

## Failure modes

Malformed URLs map to terminal CALLBACK_NOT_ALLOWED; transport failures map to delivery errors.
