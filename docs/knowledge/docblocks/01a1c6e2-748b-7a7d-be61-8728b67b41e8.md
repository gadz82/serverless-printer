# TemplatePdfRenderer

## Behavior

Resolves the descriptor bundle path inside the manifest root, reads index.html or the first HTML/Handlebars file, compiles it with the configured Handlebars mode, and renders the HTML with the template directory as the Chromium base directory.

## Why

The domain PdfRenderer takes a template descriptor and payload; this adapter owns bundle lookup, Handlebars compilation and the Chromium bridge.

## Invariants

- Bundle paths cannot escape the manifest root.
- One Chromium renderer instance is reused for the worker.
- Relative stylesheets and assets stay inside the template directory.

## Failure modes

Missing bundles, compilation errors and Chromium failures map to TemplateRenderFailed/PdfRenderFailed without leaking paths or payloads.
