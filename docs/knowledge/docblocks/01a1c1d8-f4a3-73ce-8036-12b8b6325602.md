# buildManifest

## Behavior

Reads template descriptors, hashes sorted file paths and bytes, extracts simple placeholders, validates ids/slugs and writes the release manifest.

## Why

The worker and release asset need one deterministic view of the bundled templates.

## Invariants

- Hashes are stable across runs and change on content edits.
- _smoke is the only reserved underscore slug.

## Failure modes

Duplicate ids/slugs, invalid slugs or unreadable templates fail the build; Phase 2 validation adds schema and UUID checks.

## History

R-003, R-012, S-005, S-014, ADR-005, ADR-006.
