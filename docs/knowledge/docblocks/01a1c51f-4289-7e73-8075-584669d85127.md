# previewTemplate

## Behavior

Loads the descriptor and sample/--data, compiles with lenient or strict mode, renders through the local Chrome adapter and writes .local/<slug>.pdf.

## Why

Maintainers need a real layout preview without deploying.

## Invariants

- Uses the shared engine and renderer settings.
- PDF/A is rejected until Slice 2.
- Missing Chrome/data fails clearly.

## Failure modes

Invalid slug/data, missing Chrome or render failure exits non-zero with a clear message.

## History

R-103, R-104, S-110–S-111, ADR-102.
