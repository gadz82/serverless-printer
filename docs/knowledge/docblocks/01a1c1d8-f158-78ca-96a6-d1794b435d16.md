# PrintJobError

## Behavior

Every domain failure extends this class with a stable code, a retryable flag and an optional cause.

## Why

The handler and result payload need one error taxonomy; transport adapters should not invent codes.

## Invariants

- Each subclass maps to exactly one documented code.
- Causes are preserved for diagnosis.

## Failure modes

An unclassified adapter error is normalized to a retryable PDF_RENDER_FAILED rather than leaking an arbitrary exception.
