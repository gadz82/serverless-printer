# Render regression

## Behavior

Renders generic-report with the real Lambda Chromium and PDF/A archiver, extracts page count, layout text and per-page image hashes with poppler, compares them with committed references, and supports validated reference updates and CI required mode.

## Why

Unit tests do not catch Chromium text/layout drift; committed references make plain and PDF/A rendering regressions visible in CI.

## Invariants

- The real Lambda Chromium and archiver are used, not fakes.
- PDF/A references contain pdfaid:part=2, conformance B, the 1.7 header and the GTS_PDFA1 output intent.
- Reference updates render and validate every scenario before writing any file.
- Missing poppler or non-Linux hosts skip locally but fail when CI requires the suite.

## Failure modes

Page/text/image differences, missing references or missing prerequisites fail the run with the scenario and first difference.
