# compileTemplate

## Behavior

Compiles a template with lenient, strict or assume-objects semantics, escapes output and restricts helpers to eq/formatCurrency/formatDate plus control flow.

## Why

The worker, CLI preview and validation must share one rendering contract.

## Invariants

- Prototype access is disabled.
- Unknown helpers, partials and decorators fail compilation.
- Strict errors on undefined values but accepts null/false.

## Failure modes

Compilation errors become TemplateCompileError; render/missing-value errors become TemplateRenderError.

## History

R-101, S-101–S-104, ADR-101.
