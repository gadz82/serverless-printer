# handler

## Behavior

Processes records sequentially, validates JSON and contracts, maps to domain jobs, and returns batchItemFailures for retryable or undeliverable messages.

## Why

SQS partial batch responses are the contract with the event source mapping; one bad record must not hide successful records.

## Invariants

- Messages are never deleted by the worker.
- Invalid messages with a readable SQS failure callback receive INVALID_MESSAGE.

## Failure modes

Invalid JSON or undeliverable failures are reported for DLQ; terminal delivered failures are acknowledged.
