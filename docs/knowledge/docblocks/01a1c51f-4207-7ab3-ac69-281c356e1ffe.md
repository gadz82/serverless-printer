# checkTemplates

## Behavior

Reads current and base descriptors, rejects id/slug changes, slug reuse, folder moves and missing refs, and reports new/removed templates.

## Why

Template identity is public and immutable; Git history is the version history.

## Invariants

- Existing ids/slugs never change.
- A slug cannot move to a different id.
- Folder name stays equal to slug.

## Failure modes

A missing base ref or forbidden identity change exits non-zero before merge.
