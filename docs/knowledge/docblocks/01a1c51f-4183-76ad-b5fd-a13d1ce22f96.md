# validateTemplates

## Behavior

Scans templates, enforces UUID/description/slug/identity rules, compiles sources, renders samples in assume-objects mode and warns about unbundled fonts.

## Why

Broken or inconsistent templates must fail before build/deploy.

## Invariants

- All templates are checked, not only changed ones.
- Font warnings do not fail.
- Folder name must equal slug.

## Failure modes

Any schema/compilation/sample failure exits non-zero with actionable per-template output.
