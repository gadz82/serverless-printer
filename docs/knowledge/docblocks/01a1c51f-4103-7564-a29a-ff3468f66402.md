# LocalChromeRenderer

## Behavior

Launches Chrome from CHROME_PATH or platform defaults, disables JavaScript, allows only file/data/about requests, applies A4/tagged/header-footer settings and returns PDF bytes.

## Why

Template preview must use the same page settings the Slice 2 Lambda renderer will use.

## Invariants

- External network requests are blocked.
- Chrome is closed in finally.
- Local stylesheets resolve through a base file URL.

## Failure modes

Missing Chrome, launch failures and render failures raise typed errors; PDF/A is not available in Slice 1.

## History

R-103, R-107, S-110, S-115, ADR-102.
