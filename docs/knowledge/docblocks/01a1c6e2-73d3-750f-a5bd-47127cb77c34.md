# CallbackPolicy

## Behavior

Parses the configured scheme/host/port allowlist, resolves target hostnames with an injectable resolver, and rejects loopback, link-local, metadata, non-routable and mixed unsafe answers. Named private VPC hosts remain allowed; HTTP requires an explicit allowlist.

## Why

Callbacks are caller-controlled URLs, so delivery must not become an SSRF primitive against the worker's network or the EC2 metadata service.

## Invariants

- Only allowlisted hosts and schemes pass; wildcard matching is limited to one or more subdomain labels.
- Every resolved address must be safe before a request is attempted.
- The policy returns the validated address set for the transport to pin.
- Denials throw non-retryable CallbackNotAllowed.

## Failure modes

Malformed allowlists fail configuration; malformed URLs, DNS failures and unsafe addresses deny the callback.
