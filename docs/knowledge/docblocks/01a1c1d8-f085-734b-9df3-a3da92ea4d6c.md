# validateResult

## Behavior

Compiles the result schema with Ajv 2020 and validates success/failure payloads, including template metadata and error retryability.

## Why

Callers must be able to rely on one result shape; the worker and the release smoke validate against the same schema.

## Invariants

- printing and printingExpiresAt appear together.
- Error codes and retryable flags follow the documented table.

## Failure modes

An invalid result fails validation in tests or smoke; a production adapter bug surfaces as a smoke failure rather than a silent contract break.

## History

R-002, S-005, S-008, S-014, ADR-001 — initial Phase 1 contract boundary.
