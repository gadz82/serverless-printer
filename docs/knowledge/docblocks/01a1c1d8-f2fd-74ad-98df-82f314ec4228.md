# SqsResultDelivery

## Behavior

Converts a queue ARN to a URL, sends the JSON result and sets FIFO group/deduplication identifiers from refId and message id.

## Why

SQS is the only Phase 1 callback; deterministic ids make retries and FIFO delivery safe.

## Invariants

- MessageGroupId is at most 128 characters.
- Object refIds are canonicalized before hashing.

## Failure modes

Invalid ARNs or send failures become retryable DELIVERY_FAILED errors; unsupported channels are rejected earlier by the use case.

## History

R-001, R-003, R-008, S-001, S-008, ADR-003.
