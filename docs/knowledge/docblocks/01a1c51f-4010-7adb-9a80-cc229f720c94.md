# extractPlaceholders

## Behavior

Maps each→array, if/unless→boolean, with→object and dotted paths to nested keys using null-prototype trees and safe path segments.

## Why

Callers and sample validation need one machine-readable view of the template data.

## Invariants

- Trees are null-prototype and JSON-safe.
- **proto**/prototype/constructor segments are rejected.
- Helper names are not data placeholders.

## Failure modes

Unsafe or malformed paths fail with a typed TemplateCompileError rather than mutating globals.

## History

R-102, S-105, ADR-101.
