# Release smoke test

## Behavior

Sends one plain and one PDF/A-2b _smoke job with unique refIds and SQS success/failure callbacks, waits up to 180 s for both, validates the result contract and release/template/pdfA/hash/size fields, deletes received messages and fails on timeout.

## Why

A release is only proven when the deployed package renders both a standard PDF and the PDF/A path end to end.

## Invariants

- Both scenarios are sent before polling; each refId matches exactly one result.
- Plain expects pdfA null and PDF/A expects PDF/A-2b.
- Received results are deleted even on assertion failure or timeout.
- Missing results fail at the bounded deadline.

## Failure modes

Contract validation, failed results, missing results and timeouts fail the release with the scenario/refId and error code.
