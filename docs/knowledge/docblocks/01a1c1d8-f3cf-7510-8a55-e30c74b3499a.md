# PlaceholderPdfRenderer

## Behavior

Returns a fixed valid one-page PDF without reading the template or payload.

## Why

It proves the queue/storage/delivery/release path while keeping Chromium and PDF/A out of Phase 1.

## Invariants

- Output is deterministic and dependency-free.
- It is never described as production rendering or PDF/A.

## Failure modes

The placeholder cannot fail for template content; real render failures arrive with the Chromium adapter.

## History

R-003, S-005, ADR-003.
