# buildManifest

## Behavior

Reads template descriptors, compiles HTML/HBS, extracts placeholders, hashes sorted files and returns the manifest in stable order.

## Why

The worker bundle and release asset need one deterministic template inventory.

## Invariants

- SHA-256 over sorted path+null+bytes.
- Duplicate ids/slugs and invalid descriptors fail.
- Template folders without descriptors are skipped by design.

## Failure modes

Compilation, descriptor or hashing failures abort the manifest instead of publishing a broken bundle.

## History

R-102, R-105, S-105, ADR-101, ADR-005.
