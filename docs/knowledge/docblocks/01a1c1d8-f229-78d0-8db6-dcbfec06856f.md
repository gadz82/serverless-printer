# composeWorker

## Behavior

Reads configuration, constructs the manifest catalog, S3/SQS clients, placeholder renderer, repositories and delivery, then returns the runtime once per cold start.

## Why

Explicit wiring keeps the domain free of AWS and makes every adapter replaceable in tests.

## Invariants

- No service locator or ambient client construction outside this root.
- Phase 1 passes an empty PDF/A allowed set.

## Failure modes

Invalid configuration or a missing/corrupt manifest fails before any record is processed.

## History

R-003, R-005, R-007, S-005, S-022, ADR-002, ADR-003.
