# S3PrintRepository

## Behavior

Puts the PDF with application/pdf content type, computes SHA-256 and size, and presigns a GET using the configured TTL.

## Why

The result must identify exactly one transient object and the caller must be able to fetch it without credentials.

## Invariants

- The object key is deterministic for a printId.
- The reported expiry is no later than the signed URL expiry.

## Failure modes

Storage or presign failures surface as retryable errors; the bucket default provides SSE-KMS with the project CMK.

## History

R-003, R-009, S-005, S-009, ADR-003.
