# UuidPrintIdGenerator

## Behavior

Uses a committed namespace UUID and the inbound message id to produce the same print id on every retry.

## Why

Retries overwrite the same object and callers can deduplicate on printId.

## Invariants

- The namespace is committed and stable.
- The same message id always yields the same print id.

## Failure modes

Changing the namespace breaks caller deduplication and requires a contract decision.
