# Task

Implement the template authoring and guard commands using the shared engine, and expose them as
root pnpm scripts.

# Constraints

- Scripts are `.mjs` and load the TypeScript engine through the existing `tsx` loader (the smoke
  script shows the pattern). No duplicate Handlebars logic.
- `template:new <slug>` validates the slug, creates `templates/<slug>/` with `template.json` (fresh
  UUID v4), a minimal `index.html`, `styles.css` and `sample.json`; it refuses to overwrite.
- `template:validate` scans every template, validates the descriptor schema, unique ids/slugs,
  Handlebars compilation, `sample.json` against the placeholder tree, and warns (without failing)
  for CSS font-family values that are neither bundled nor default fonts.
- `template:check --base <ref>` reads each `template.json` at the base via Git and fails when an
  existing id/slug changed or a slug is reused by a different id. A missing ref fails clearly.
- `template:manifest` replaces the Phase 1 script with the engine builder and preserves the
  release/RELEASE behaviour.
- Root `package.json`: add `template:new`, `template:validate`, `template:check` and
  `template:preview` scripts. Preview points to the P-103 script.
- Tests use temporary directories and a temporary Git repo; do not mutate the real templates.
- Follow `style-example.ts`; no `any`.

# Out of scope

- Preview rendering and the generic-report template (P-103).
- Chromium, PDF/A, network, CI changes.
