# Task

Create the shared template engine that compiles Handlebars in the three spec modes, exposes only
the fixed helper set, extracts the placeholder tree and builds the release-aware manifest.

# Constraints

- Only this prompt edits `pnpm-workspace.yaml` and `pnpm-lock.yaml`: add `handlebars` `^4.7.10`
  and `puppeteer-core` `^25.16.0` to the catalog. No other new dependency.
- Package name `@printer/template-engine`, ESM, strict TypeScript, no AWS/Chromium imports in the
  engine itself; manifest file reading may use `node:fs`.
- Modes: `lenient` missing fields render empty; `strict` any missing field fails;
  `assume-objects` fails only when a parent object is missing. Use Handlebars strict/assumeObjects
  settings and keep prototype access disabled.
- Fixed helpers: `eq`, `formatCurrency`, `formatDate`; templates cannot register helpers.
- Placeholder AST: `{{#each x}}` → array, `{{#if x}}`/`{{#unless x}}` → boolean,
  `{{#with x}}` → object, `{{a.b}}` → nested key. Return a JSON-safe tree.
- Content hash: SHA-256 over sorted `path + "\0" + bytes`; stable across runs, changes on content.
- Manifest: `release` plus per-template `id`, `slug`, `name`, `path`, `contentHash`,
  `placeholders`; deterministic order.
- Export a small API (`compileTemplate`, `extractPlaceholders`, `hashTemplateFiles`,
  `buildManifest`, descriptor validation) for the CLI/worker. No `any`.
- Follow `hexagonal-port.ts`/`style-example.ts` shapes; why-only comments.

# Out of scope

- CLI commands, preview, Chromium adapter, PDF/A, network, worker changes.
- No AWS calls.
