# Task

Create the single pnpm workspace and the shared quality toolchain every later prompt depends on.
The workspace must install once, expose the commands used by CI and developers, and enforce the
domain boundary from the first line of code.

# Constraints

- `packageManager` is `pnpm@10.34.9`; engines require Node `>=24`.
- The workspace contains `apps/*` and `packages/*`; the root package is private.
- Put every runtime and development dependency in the `pnpm-workspace.yaml` catalog with the
  versions below. Later prompts reference `catalog:` and must not add dependencies.
  - Runtime: `@aws-sdk/client-s3` `^3.1164.0`, `@aws-sdk/client-sqs` `^3.1164.0`,
    `@aws-sdk/s3-request-presigner` `^3.1164.0`, `ajv` `^8.20.0`, `uuid` `^14.0.3`.
  - Development: `typescript` `^5.9.3`, `tsx` `^4.23.15`, `vitest` `^3.2.7`, `eslint`
    `^9.39.5`, `@eslint/js` `^9.39.5`, `typescript-eslint` `^8.72.1`, `globals` `^17.14.0`,
    `eslint-config-prettier` `^10.1.8`, `prettier` `^3.9.10`, `esbuild` `^0.28.2`,
    `json-schema-to-typescript` `^16.0.0`, `@commitlint/cli` `^21.2.4`,
    `@commitlint/config-conventional` `^21.2.4`, `husky` `^9.1.7`, `semantic-release`
    `^25.0.9`, `@semantic-release/changelog` `^7.0.0`, `@semantic-release/commit-analyzer`
    `^13.0.1`, `@semantic-release/exec` `^7.1.0`, `@semantic-release/git` `^11.0.1`,
    `@semantic-release/github` `^12.0.10`, `@semantic-release/release-notes-generator`
    `^14.1.1`, `@types/aws-lambda` `^8.10.164`, `@types/node` `^24.19.2`.
- Scripts: `lint`, `format:check`, `typecheck` (`pnpm -r --if-present typecheck`), `test`
  (`vitest run --passWithNoTests`), `test:contract` (contracts filter), `test:integration`
  (`vitest run tests/integration --passWithNoTests`), `template:manifest`,
  `build:worker`, `local:setup`, `worker:local`, `sink:local`, `smoke:local`, `smoke:test`.
- TypeScript strict mode with `noUncheckedIndexedAccess`, `noImplicitOverride`,
  `verbatimModuleSyntax`, `module`/`moduleResolution` NodeNext, target ES2022.
- ESLint flat config must reject `@aws-sdk/*`, `aws-lambda`, `node:fs`, `node:http`, `node:https`
  and `@printer/render-worker` imports from `packages/domain/**/*.ts`. This is the architecture
  boundary as an executable gate.
- Vitest includes `packages/**/*.test.ts`, `apps/**/*.test.ts`, `scripts/**/*.test.*` and
  `tests/**/*.test.ts`, environment `node`.
- Commitlint extends `@commitlint/config-conventional`; husky's `commit-msg` runs
  `pnpm exec commitlint --edit "$1"`.
- `.gitignore` includes `node_modules/`, `dist/`, `coverage/`, `.local/`, `.terraform/`,
  `*.tfstate`, `*.tfstate.*`, `templates.manifest.json`, `.release-version`, `.DS_Store`.
- README explains the architecture boundaries, the local LocalStack path, the cloud path and the
  fact that Phase 1 emits a placeholder PDF and rejects PDF/A and non-SQS channels.
- Steering: `architecture-boundaries`, `code-style`, `code-examples`, `repository-flow`,
  `repository-trunk-based`. Follow `style-example.ts` for explicit types and why-only comments.

# Out of scope

- No application, contract, domain, infra or workflow code.
- No CI or release workflow.
- No dependency outside the catalog.
