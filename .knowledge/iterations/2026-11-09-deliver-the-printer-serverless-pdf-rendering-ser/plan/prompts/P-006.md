# Task

Prove the same worker code runs as plain Node against LocalStack and that the queue → worker →
S3 → SQS callback path works locally, with a recorded callback sink and executable integration
tests.

# Constraints

- `docker-compose.yml` starts LocalStack with `SERVICES=sqs,s3` on port 4566 and a healthcheck.
  Add a `callback-sink` service using `node:24-alpine`, the repository mounted at `/workspace`,
  and `node scripts/local-callback-sink.mjs`; it depends on LocalStack being healthy. Document
  that `pnpm install` must run on the host first.
- `scripts/local-setup.mjs` idempotently creates `printer-jobs`, `printer-jobs-dlq` and
  `printer-smoke-results` queues and the `printer-prints-local` bucket in LocalStack, using
  `AWS_ENDPOINT_URL` and dummy credentials. It also generates `templates.manifest.json` through
  `buildManifest`.
- `scripts/local-worker.mjs` polls the jobs queue with long polling, builds a Lambda SQS event
  with `ApproximateReceiveCount`, invokes the handler, deletes successful records, leaves
  records listed in `batchItemFailures` for redelivery, and logs only ids/outcome.
- `scripts/local-callback-sink.mjs` polls the smoke-results queue, appends one JSON line per
  result to `.local/results.jsonl`, deletes the message and prints a short line.
- `scripts/smoke-local.mjs` sends one valid `_smoke` job with an SQS callback to the smoke-results
  queue, waits up to 30 seconds for a matching `refId` in `.local/results.jsonl`, prints the
  result and exits non-zero on timeout.
- Integration tests under `tests/integration/` use the LocalStack endpoint, unique resource
  names per run, and clean up. Cover the matrix listed in deliverables; use a fake renderer
  override only for retryable/last-attempt failures, and real SQS/S3 otherwise.
- Tests must not depend on Docker Compose if LocalStack is already reachable; read
  `AWS_ENDPOINT_URL` with `http://localhost:4566` as the default.
- The local runner and sink import the worker and contracts; do not duplicate domain logic.
- Steering: `architecture-boundaries`, `code-examples`, `code-style`, `repository-flow`,
  `repository-trunk-based`.

# Out of scope

- Terraform, CI workflow, release workflow and cloud smoke.
- Chromium, PDF/A and non-SQS channels.
- No dependency outside the P-001 catalog.
