# Task

Create the pull-request CI that proves code, contracts, LocalStack integration and Terraform are
valid before a change can reach the protected `main` branch.

# Constraints

- Trigger: `pull_request` to `main`; permissions `contents: read`, `id-token: write` only where
  the plan job needs OIDC, `pull-requests: write` for the plan summary.
- Use Node 24, pnpm 10.34.9 and `pnpm install --frozen-lockfile`.
- `quality` job: `pnpm lint`, `pnpm exec prettier --check .`, `pnpm typecheck`, `pnpm test`,
  `pnpm test:contract`.
- `integration` job: LocalStack service container `localstack/localstack:4` with
  `SERVICES=sqs,s3`, port 4566 and a healthcheck; run `pnpm test:integration` with
  `AWS_ENDPOINT_URL=http://localhost:4566` and dummy credentials.
- `terraform` job: install Terraform ≥ 1.11 and tflint, run `terraform fmt -check`,
  `terraform init -backend=false`, `terraform validate`, `tflint --init`, `tflint`. If
  `vars.AWS_PLAN_ROLE_ARN` and `vars.AWS_REGION` are present and the PR is not from a fork,
  configure AWS credentials with the read-only plan role, init the S3 backend with
  `TF_STATE_BUCKET`/`TF_STATE_KEY`, run `terraform plan -out=plan.out`, render a plan summary and
  post it to the PR. Otherwise emit a clear notice and do not pretend the plan ran.
- `commitlint` job: fetch full history, run commitlint from the PR base SHA to the head SHA, and
  validate the PR title with `amannn/action-semantic-pull-request@v5` (or an equivalent
  Conventional Commits check).
- No job may deploy, apply Terraform, create AWS resources, or use static AWS keys.
- `tflint.hcl` enables the AWS ruleset and is used by the terraform job.
- Keep the workflow readable: named steps, pinned major versions, no inline scripts longer than
  necessary. Use `pnpm/action-setup@v4` and `actions/setup-node@v4` with pnpm cache.
- Steering: `repository-flow`, `repository-trunk-based`, `code-style`.

# Out of scope

- Release workflow, semantic-release, smoke test and rollback (P-010).
- Any AWS resource creation or Terraform apply.
- No dependency outside the P-001 catalog.
