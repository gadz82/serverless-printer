# Task

Create the one-time Terraform bootstrap that makes the single deployment and the GitHub OIDC
release path possible, without any static AWS credentials.

# Constraints

- Terraform `>= 1.11`, AWS provider `~> 6.0`, TLS provider for the GitHub OIDC thumbprint.
- Variables: `name_prefix` (default `printer`), `region` (default `eu-central-1`),
  `github_owner`, `github_repo`, `create_oidc_provider` (default true), optional
  `state_bucket_name`, optional `artifacts_bucket_name`, and `tags`.
- Buckets: `<prefix>-tfstate` and `<prefix>-artifacts`, versioned, encrypted, all public access
  blocked. Allow explicit overrides for global name collisions. The artifacts bucket holds
  `<release>/render-worker.zip`.
- OIDC provider `token.actions.githubusercontent.com`; when `create_oidc_provider` is false, look
  it up with a data source instead of creating a duplicate.
- Deploy role trust: only `repo:<owner>/<repo>:ref:refs/heads/main`, audience
  `sts.amazonaws.com`. Plan role trust: only `repo:<owner>/<repo>:pull_request`.
- Deploy role permissions are scoped to the project's state, artifacts, queue, prints bucket,
  KMS key, Lambda, IAM roles/policies, log group and alarms. Plan role is read-only plus read
  access to the state bucket. Do not use administrator access for the deploy role.
- Bootstrap uses local state and is not run by CI (ADR-004). The README records the apply
  command, the outputs, the secure state-storage instruction and the GitHub repository
  variables that must be set: region, deploy role ARN, plan role ARN, state bucket/key, artifacts
  bucket.
- Outputs: `state_bucket`, `artifacts_bucket`, `deploy_role_arn`, `plan_role_arn`,
  `oidc_provider_arn`.
- No VPC, no application resources, no environments.
- Steering: `repository-flow`, `repository-trunk-based`. The bootstrap is an operator step, not a
  prompt branch merge target.

# Out of scope

- `infra/modules/printer`, the root deployment, CI and release workflows.
- Applying the stack against a real AWS account.
- No dependency outside the P-001 catalog.
