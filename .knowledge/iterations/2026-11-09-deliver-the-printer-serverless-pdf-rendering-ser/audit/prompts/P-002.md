# Task

Publish the public job and result contracts as JSON Schema 2020-12, validate them with Ajv, and
commit generated TypeScript types that cannot drift from the schemas.

# Constraints

- `packages/contracts/schemas/job.schema.json` and `result.schema.json` are the source of truth;
  `src/generated/` is generated with `json-schema-to-typescript` and committed.
- The job schema requires `templateId`, `refId` and `webhooks.success`; `options` and `payload`
  are optional; `additionalProperties` is false at every object level.
- `templateId` accepts a UUID, the reserved `_smoke` slug, or a normal slug matching
  `^[a-z][a-z0-9-]{2,63}$`.
- `refId` is exactly string, number or object; arrays, booleans and null are rejected.
- `options.pdfA` is `false` or one of the eight levels from the spec; the worker enforces the
  configured allowed list, not the schema.
- `webhooks.success.channel` is `http|lambda|sqs|eventBridge|s3`; the failure channel excludes
  `s3`. Validate `http` values and `pingUrl` as HTTPS URLs, ARN channels as ARN-shaped strings,
  and `s3` as an HTTPS presigned PUT URL. `pingUrl` is optional/null.
- The success result requires `success: true`, `printId`, `refId`, `sha256`, `sizeBytes`, `pdfA`,
  `template`, `renderedAt`; `printing` and `printingExpiresAt` are optional but must appear
  together. The failure result requires `success: false`, `printId`, `refId`, nullable
  `template`, `error` and `failedAt`; `error.code` is one of the eight spec codes and
  `error.attempts` is ≥ 1.
- Use `Ajv2020` in strict mode; export a typed `validateJob`/`validateResult` and a stable error
  formatter. Do not use `any`.
- Contract version is `1.0.0`; export it as a constant.
- Fixtures must cover the matrix in `assessment/regression-plan.md`, including all channels,
  invalid `templateId`, bad `pdfA`, `s3` failure channel, non-HTTPS URLs, unknown fields, bad
  hash length and unknown error codes.
- Follow `style-example.ts` for named errors, explicit types and why-only comments. No AWS or
  filesystem imports.
- Steering: `architecture-boundaries`, `solid-principles`, `code-style`, `code-examples`.

# Out of scope

- No worker handler, no domain use case, no template engine.
- No dependency outside the P-001 catalog.
