# Task

Create the single real `_smoke` template identity and the small build-time manifest generator
that proves template resolution and content traceability in Phase 1.

# Constraints

- `template.json` fields: `id` (fresh UUID v4, generated once), `slug: "_smoke"`, `name`,
  `description`. The id is never regenerated by tests.
- `_smoke` is the only slug that may start with an underscore (ADR-006). Every other slug must
  match `^[a-z][a-z0-9-]{2,63}$`; the script fails on any other leading underscore.
- `index.html` is self-contained, uses `lang="en"`, semantic elements and a `{{message}}`
  placeholder. No external requests, fonts, scripts or styles.
- `sample.json` is `{"message":"Printer smoke"}`.
- `scripts/template-manifest.mjs`:
  - reads `templates/*/template.json`;
  - ignores dot files and sorts file paths deterministically;
  - hashes file contents with SHA-256 over sorted `path + "\0" + bytes` entries;
  - writes `templates.manifest.json` at the repository root with `release`, and per template
    `id`, `slug`, `name`, `path`, `contentHash`, `placeholders`;
  - reads `release` from `RELEASE` and defaults to `local`;
  - fails on duplicate ids or slugs and on an invalid slug;
  - extracts simple `{{identifier}}` placeholders as string values (full Handlebars AST is
    Phase 2);
  - exports `buildManifest(root, release)` for tests and local tooling, with the CLI guarded so
    importing it does not write files.
- The script must be deterministic: two runs over unchanged files produce identical bytes.
- Add a Node-compatible test file at `scripts/template-manifest.test.mjs` using Vitest and
  temporary directories; do not mutate `templates/_smoke`.
- Steering: `code-style`, `code-examples`, `repository-flow`. This script is transitional and
  must not grow into a template engine (ADR-005).

# Out of scope

- `packages/template-engine`, `template:new`, `template:validate`, `template:check`,
  `template:preview` and release-asset publication.
- No dependency outside the P-001 catalog.
