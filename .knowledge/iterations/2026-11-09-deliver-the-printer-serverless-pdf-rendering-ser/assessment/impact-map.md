## Explicit non-impact

- No API, UI, database, template editor, runtime upload, environment, or version/status model.
- No Chromium, PDF/A conversion, render regression, HTTP/lambda/eventBridge/s3 delivery, ping,
  load test or production alarms in this increment.
- No `modules/network`; the worker stays outside a VPC in Phase 1. The optional network module
  arrives in Phase 2.

## Dependency direction check

`apps/render-worker → packages/domain → packages/contracts`; adapters implement domain ports.
`infra/` and workflows do not import application code. The placeholder renderer is selected only
at the composition root, so replacing it with Chromium later does not change the use case or the
contract.
