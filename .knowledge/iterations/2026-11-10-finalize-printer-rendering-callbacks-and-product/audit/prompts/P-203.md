# Task

Implement the HTTP callback/ping allowlist and SSRF policy that the delivery adapters will use.

# Constraints

- Allowlist entries are `scheme://host[:port]`; a `*.` prefix matches subdomains, exact hosts
  otherwise. `http` is only valid when explicitly allowlisted; HTTPS required otherwise.
- Resolve DNS before the request and reject link-local/metadata targets such as
  `169.254.169.254` and `fd00:ec2::254`; reject loopback when not explicitly required. Private
  VPC targets are allowed when the allowlist names the host (private callbacks are a use case).
- Fail with `CALLBACK_NOT_ALLOWED` at the job boundary; do not log full URLs.
- No HTTP client here; the policy is a pure async resolver with injectable DNS for tests.
- Keep the 4 KB env constraint in mind; parsing is simple.

# Out of scope

- HTTP delivery/ping implementation (P-204), renderer, Terraform.
- No new dependency.
