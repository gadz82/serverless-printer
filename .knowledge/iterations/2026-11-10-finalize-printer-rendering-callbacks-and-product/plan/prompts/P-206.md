# Task

Harden the local Chrome preview before its patterns are reused by the Lambda renderer.

# Constraints

- `file:` requests are allowed only under the template/base directory; reject
  `file:///etc/...` and symlink escapes.
- If `CHROME_PATH` is set but invalid, fail with a clear error; do not fall back silently.
- Preserve the original render error if browser close fails; surface request interception errors.
- Keep existing preview behavior/tests passing.
- No new dependency.

# Out of scope

- Lambda renderer, PDF/A, channels.
- No deployed changes.
