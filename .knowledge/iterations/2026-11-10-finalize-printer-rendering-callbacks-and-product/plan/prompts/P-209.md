# Task

Make the release package and smoke test cover real Chromium rendering and PDF/A.

# Constraints

- `build-worker.mjs`: mark `@sparticuz/chromium`/Chromium binary external in esbuild; copy the
  Chromium package, templates, manifest and sRGB ICC into the zip; keep the createRequire banner
  and post-build handler import check.
- `smoke-test.mjs`: send one plain `_smoke` job and one `pdfA: "PDF/A-2b"` job, each with an SQS
  callback/refId; poll both, validate the result contract, assert release/template/hash/size and
  `pdfA` values; delete messages; fail on timeout.
- Release workflow: keep OIDC/apply/rollback; run both smoke jobs; pass the Terraform release and
  default PDF/A levels. Do not add static keys.
- Terraform `pdfa_allowed_levels` default returns to all eight levels (P-207 owns infra; coordinate
  in the report if still Slice 1 default).
- No PDF/A validator; best effort.

# Out of scope

- Renderer/archiver code, channel code, alarms, load test.
- No new dependency.

Write blockers/interface changes to `plan/prompts/_bus/outbox/P-209/`. Report the zip contents,
smoke matrix and exact results. Do not write into `.knowledge`.
