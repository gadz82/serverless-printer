# Task

Implement PDF/A post-processing behind the new `PdfArchiver` port using pdf-lib.

# Constraints

- `pdf-lib` is already a worker dependency from P-201.
- Implement all eight levels. Set the PDF version and trailer document ID, embed a valid sRGB ICC
  output intent, write XMP `pdfaid:part`/`pdfaid:conformance`, and keep the Info dictionary
  consistent (title, producer, creation date, language from `<html lang>` when available).
- Check for encryption, JavaScript and unembedded fonts; fail with
  `PDFA_CONVERSION_FAILED` with a clear cause. No external validator.
- Bundle a standard sRGB ICC profile under `apps/render-worker/src/pdfa/`; do not fetch at runtime.
  Use the system ColorSync sRGB profile or another redistributable standard profile; document its
  source.
- Wire the archiver behind the port only; do not modify the use case beyond consuming the port.
- PDF/A remains best effort; no false validation claim.

# Out of scope

- Channels, renderer changes, Terraform, load tests.
- No PDF/A validator.

# Report back

Write blockers/interface changes to `plan/prompts/_bus/outbox/P-202/`. Report the level matrix,
safety checks and exact results. Do not write into `.knowledge`.
