# Task

Implement the four remaining result channels and ping behind the existing delivery port.

# Constraints

- HTTP: POST JSON, `X-Printer-Print-Id`, 5 s timeout, any 2xx delivered; allowlist/DNS policy from
  P-203 first.
- Lambda: `Invoke` with `InvocationType=Event`; body is the result.
- SQS: preserve FIFO identifiers; send result JSON.
- EventBridge: `PutEvents` with `EVENT_SOURCE` (default printer) and
  `printer.print.succeeded|failed`; detail is the result.
- S3: PUT PDF with `Content-Type: application/pdf` to the presigned URL; omit
  `printing`/`printingExpiresAt`.
- Ping after channel delivery: POST `{success: true|false}` to `pingUrl`, through the same policy;
  a ping failure is logged, not a result-delivery failure.
- Use AWS SDK v3 clients behind the composition root; no globals. Use Node `fetch` for HTTP/S3.
- Map failures to the existing retryable/terminal delivery errors; do not log URLs/refId.
- Do not edit Terraform; P-207 supplies channel IAM.

# Out of scope

- Renderer, PDF/A, role modes, alarms.
- No new dependency.

Write blockers/interface changes to `plan/prompts/_bus/outbox/P-204/`. Report the channel matrix and
exact results. Do not write into `.knowledge`.
