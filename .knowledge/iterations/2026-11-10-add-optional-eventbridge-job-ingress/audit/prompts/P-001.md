# Task

Add the optional EventBridge job-ingress rule from SPEC §6.4.

# Constraints

- `job_rule = { bus_name = string, event_pattern = string }`, default `null`.
- Validate a non-empty bus name and valid JSON event pattern; reject invalid input at plan time.
- When set, create one EventBridge rule on the named bus and one target to the existing jobs queue.
- Add a jobs queue-policy statement allowing `events.amazonaws.com` to send only when
  `aws:SourceArn` matches the rule ARN.
- Default `null` must create no EventBridge resources or policy statements.
- Do not change the job/result contract, worker, callbacks, templates, CI or alarms. The bootstrap deploy-role EventBridge permissions are in scope.
- Follow `assessment/infrastructure-impact.md`; add only the scoped EventBridge permissions to the
  bootstrap deploy role, never to the main/worker role.

# Out of scope

- Scheduling, cross-account buses, rule DLQs, live AWS apply.
- New outputs; the rule name is deterministic.

# Report back

Write blockers/interface changes to `plan/prompts/_bus/outbox/P-001/`. Report the resource
matrix, queue-policy evidence, validation/plan results and residual risks. Do not write into
`.knowledge`.
