# Task

# Constraints

- Eight examples: HTTP standard, HTTP PDF/A, Lambda, SQS FIFO, EventBridge, S3 PDF/A, private HTTP
  via VPC, optional EventBridge ingress.
- Each folder gets `README.md`, `job.json` (or `event.json` for ingress) and
  `config.tfvars.example`.
- Use the `generic-report` template and synthetic data; placeholders may use example.com and
  account 123456789012, clearly marked for replacement.
- Add `tests/examples/examples.test.ts` to validate every job and the ingress detail with
  `validateJob`, enforce 6–8 examples, and require the three files.
- Link the examples index from the root README and usage guide.
- No application, Terraform, workflow or contract changes.

# Out of scope

- Real sends, live AWS resources, new channels or more than eight examples.
